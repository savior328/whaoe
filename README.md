# 🏨 小旅馆 - 奇葩客人模拟经营游戏

> 一家小旅馆，一群奇葩客人，一段爆笑的经营之旅

## 🎮 游戏简介

你接手了一家小旅馆。每天要做的就是：
- 定房价
- 接待客人
- 处理奇葩事件
- 赚钱升级

**核心卖点**：遇到各种奇葩客人，每次选择都会影响你的收入和口碑！
